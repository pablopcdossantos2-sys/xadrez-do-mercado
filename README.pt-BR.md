# Trading Tape Puzzles

> Enigmas de xadrez, mas para day traders de futuros.

Treinador de navegador para scalpers de futuros MES e MNQ.
Cada puzzle apresenta price action intradiario e pede uma decisao:
Long, Short ou Skip. Avaliado por um analista baseado em regras.

## Inicio rapido

Abra index.html em qualquer navegador moderno. Sem build, sem install.

## Recursos

- Loop em tres fases: Decisao -> Replay -> Resultado
- Classificador de playbook (Reclaim de VWAP, ORB, Rompimento Falho, etc.)
- Debrief contrafactual (o que teria acontecido com o outro lado)
- VWAP, 200 EMA, DEMA, volume, niveis de sessao
- Interface bilingue (EN / PT-BR)
- Estatisticas persistentes (ELO, precisao, streaks, R total)
