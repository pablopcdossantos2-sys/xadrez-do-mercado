# Trading Tape Puzzles

> Chess puzzles, but for futures day traders.

Browser-based trainer for MES and MNQ futures scalpers.
Each puzzle presents intraday price action and asks for one decision:
Long, Short, or Skip. Answer is graded against a rule-based analyst.

## Quick start

Open index.html in any modern browser. No build, no install.

## Features

- Three-phase loop: Decision -> Replay -> Result
- Playbook classifier (VWAP Reclaim, ORB, Failed Breakdown, etc.)
- Counterfactual debrief (what if you had chosen the other side)
- VWAP, 200 EMA, DEMA, volume, session levels
- Bilingual UI (EN / PT-BR)
- Persistent stats (ELO, accuracy, streaks, total R)
