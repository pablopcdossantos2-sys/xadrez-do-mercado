# How to Create Puzzles

A puzzle is `{ history: [...82 bars], future: [...38 bars] }`, generated by `src/data.ts`.

Each bar is `{ time, open, high, low, close, volume }`.

## Pipeline

`src/data.ts` (`generateMarketData`) -> `src/analytics.ts` (`classifySetup` / `analyzePuzzle`) -> `src/App.tsx`

## Setups

`liq_sweep_long`, `liq_sweep_short`, `vwap_reclaim`, `vwap_reject`,
`orb_long`, `orb_short`, `failed_breakdown`, `failed_breakout`,
`pullback_long`, `pullback_short`, `range_fade_long`, `range_fade_short`,
`momentum_long`, `momentum_short`, `consolidation`.

## Adding a new setup

Insert a new condition in `classifySetup()` before the momentum fallback. Return the setup id, English/Portuguese labels, and directional bias.

## Real historical data

The current application intentionally generates synthetic procedural data. A future historical-data adapter should preserve the 82-bar history / 38-bar future contract before passing samples to the same analysis pipeline.
